import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

The FAIRSCAPE Web Server provides a React-based interface for viewing metadata and managing RO-Crates uploaded to FAIRSCAPE. It offers comprehensive visualization and management capabilities for your research objects.

## Capabilities

<CardGrid>
  <Card title="Dashboard Interface" icon="bars">
    Access a centralized dashboard to view and manage all uploaded RO-Crates. Get quick access to downloads and detailed landing pages for each research object in your collection.
  </Card>
  <Card title="Metadata Visualization" icon="puzzle">
    Explore comprehensive landing pages featuring JSON-LD metadata summaries, file listings, and interactive evidence graph visualizations. View metadata in multiple formats including JSON-LD, RDF, and Turtle.
  </Card>
  <Card title="Publication Support" icon="rocket">
    Streamline your research sharing with direct publication support to Harvard Dataverse instances. Easily make your research objects available to the wider scientific community.
  </Card>
</CardGrid>
