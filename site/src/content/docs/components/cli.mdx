A utility for packaging objects and validating metadata for FAIRSCAPE. This command-line tool enables researchers to create and manage Research Object Crates (RO-Crates) with comprehensive metadata support.

## Capabilities

<CardGrid>
  <Card title="RO-Crate Management" icon="open-book">
    Create and manage Research Object Crates following the RO-Crate specification for lightweight research data packaging.
  </Card>
  <Card title="Metadata Registration" icon="pencil">
    Register and manage comprehensive metadata for all objects within your research crates.
  </Card>
  <Card title="Schema Validation" icon="approve-check">
    Define and validate schemas for tabular datasets, ensuring data quality and consistency.
  </Card>
</CardGrid>
