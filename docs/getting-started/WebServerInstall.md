# FAIRSCAPE Web Server

The FAIRSCAPE Web Server provides a React-based interface for viewing metadata and managing RO-Crates uploaded to FAIRSCAPE.

## Installation

1. Clone the repository:
```bash
git clone https://github.com/fairscape/FairscapeFrontEnd
```
2. Install dependencies:
```bash
cd FairscapeFrontEnd
npm install
```
3. Start the development server:
```bash
npm run dev
```
