# FAIRSCAPE Server (MDS)

The Metadata Service (MDS) is the core backend service of FAIRSCAPE, responsible for metadata management and digital object handling.

## Features

The FAIRSCAPE server provides:

- **Metadata Management**
- **Persistent Identifiers**
- **Storage Management**
- **Provenance Tracking**
