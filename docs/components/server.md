  <h1>FAIRSCAPE Server</h1>
  
  <div class="component-card intro-card">
    <h2>Overview</h2>
    <p>The FAIRSCAPE Server is the core backend service of FAIRSCAPE, responsible for metadata management and digital object handling. As the foundation of the FAIRSCAPE ecosystem, it provides robust data management capabilities and REST API access for seamless integration.</p>
  </div>

  <div class="feature-grid">
    <div class="component-card feature-card">
      <h3>Package Management</h3>
      <div class="feature-content">
        <div class="feature-icon">📦</div>
        <p>Comprehensive handling of RO-Crate packages including receiving, cataloging, indexing, and secure storage of uploaded content. Built-in validation ensures data integrity throughout the process.</p>
      </div>
    </div>
    
    <div class="component-card feature-card">
      <h3>Metadata Processing</h3>
      <div class="feature-content">
        <div class="feature-icon">🔍</div>
        <p>Advanced metadata extraction and registration system that processes components and their associated metadata. Enables rich semantic descriptions and efficient data discovery.</p>
      </div>
    </div>
    
    <div class="component-card feature-card">
      <h3>Provenance Tracking</h3>
      <div class="feature-content">
        <div class="feature-icon">🔗</div>
        <p>Sophisticated provenance graph handling with capabilities. Maintains complete lineage of data transformations and relationships.</p>
      </div>
    </div>
