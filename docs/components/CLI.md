<div class="documentation-page">
  <h1>FAIRSCAPE Command Line Interface (CLI)</h1>
  
  <div class="component-card intro-card">
    <h2>Overview</h2>
    <p>A utility for packaging objects and validating metadata for FAIRSCAPE. This command-line tool enables researchers to create and manage Research Object Crates (RO-Crates) with comprehensive metadata support.</p>
  </div>

  <div class="feature-grid">
    <div class="component-card feature-card">
      <h3>RO-Crate Management</h3>
      <p>Create and manage Research Object Crates following the RO-Crate specification for lightweight research data packaging.</p>
    </div>
    
    <div class="component-card feature-card">
      <h3>Metadata Registration</h3>
      <p>Register and manage comprehensive metadata for all objects within your research crates.</p>
    </div>
    
    <div class="component-card feature-card">
      <h3>Schema Validation</h3>
      <p>Define and validate schemas for tabular datasets, ensuring data quality and consistency.</p>
    </div>
  </div>
