# FAIRSCAPE Web Server

The FAIRSCAPE Web Server provides a React-based interface for viewing metadata and managing RO-Crates uploaded to FAIRSCAPE.

## Features

- **Dashboard**: View all uploaded RO-Crates with download and landing page links
- **Landing Pages**: For each RO-Crate, providing:
    - Table summary of required JSON-LD metadata
    - List of contained files
    - Multiple metadata format views:
        - JSON-LD
        - RDF
        - Turtle
    - Interactive d3 visualization of evidence graphs
- **Publication Support**: Direct publication to Harvard Dataverse instances
